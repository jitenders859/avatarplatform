Zapier & CRM Integration

AvatarPlatform doesn't have native CRM connectors (HubSpot, Salesforce, etc.) yet — but every project already has a signed outbound webhook, and Zapier's "Webhooks by Zapier" trigger can catch it directly. This gets you into 5,000+ apps (HubSpot, Salesforce, Slack, Google Sheets, email) without any code.

Step 1 — Set your webhook URL

In Zapier, create a new Zap and choose Webhooks by Zapier → Catch Hook as the trigger. Zapier gives you a unique URL like https://hooks.zapier.com/hooks/catch/123456/abcdef/.

Paste that URL into your project's Settings tab → Webhook URL field, and save.

Step 2 — Verify the signature (recommended)

Every request carries an X-Avatar-Signature: sha256=<hmac> header, computed over the raw JSON body using your project's webhook secret (shown in the same Settings tab). Zapier's built-in "Code by Zapier" step can verify this before continuing, the same way any other webhook receiver would:

const crypto = require('crypto');
const expected = 'sha256=' + crypto.createHmac('sha256', WEBHOOK_SECRET).update(rawBody).digest('hex');
if (expected !== receivedSignature) throw new Error('Invalid signature');

Step 3 — Filter by event type

Two event types are sent to the same URL — add a Zapier Filter step keyed on the event field so a "New Lead" Zap doesn't also fire on every chat message:

eventFires whenTypical Zap
leadA visitor completes your capture form (all required fields filled)Create/update a CRM contact (HubSpot, Salesforce, Pipedrive…)
messageEvery visitor chat messageLog to a spreadsheet, post to Slack for review
handoff_requestedA visitor asks to talk to a human (see live agent handoff)Notify your support team (Slack, email, SMS)

Lead payload

{
  "event": "lead",
  "publicId": "abc123",
  "sessionId": "uuid",
  "leadId": "uuid",
  "data": { "email": "visitor@example.com", "name": "Jane Doe" },
  "timestamp": 1747221600000
}
💡

Map data's keys to your capture fields' key values (configured in the Settings tab's capture form editor) — they're the same across every lead payload for a given project, so the Zapier field mapping only needs to be set up once per Zap.

⚠️

Only one webhook URL per project today — if you need both a Zapier Zap and a custom integration, point the webhook at your own endpoint and forward to Zapier's catch-hook URL from there.
